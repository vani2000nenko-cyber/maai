# maai
Meldo AI Aggregator — Android-приложение для работы с ИИ-моделями OpenCode, Go и Zen через локально хранящиеся API-ключи. Стек: Kotlin 2.0, Jetpack Compose, Material 3 (Material You), Hilt, Retrofit, DataStore. Требует Android 8.0+. Есть чат, онбординг-политика и автосборка через GitHub Actions. Лицензия MIT.
